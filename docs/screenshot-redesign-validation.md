## Результат и границы

Обновлены shell, главная, списки и карточки; добавлены frontend семей/детей/
родительского кабинета, платежей/счетов/тарифов/абонементов, документов,
уведомлений, профиля, финансового отчёта и настроек. Оригинальная локальная
эмблема и Rubik сохранены. В данных нет жёстких демонстрационных показателей;
при отсутствии нового API пользователь видит подготовку раздела. Успех записи
отображается только после успешного ответа API.

Новые разделы проверены на **синтетических контрактных ответах**. Это проверка
frontend и формы запросов, а не приёмка реальных денег, серверных прав, хранения
файлов или новых таблиц. Для документов проверены upload payload и ссылка
авторизованного скачивания; фактическая бинарная выдача относится к #203.
Платёжная кнопка iPay не создаёт запросов и не подтверждает оплату.

Debian-контейнере и скопированы в `/tmp/rd08-browser-libs/lib`; системные пакеты

host validator Playwright не учитывает пользовательский каталог, поэтому для
локального запуска использован `PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1`.
В CI применяется штатный `playwright install --with-deps`.

Во время локальных WebKit прогонов обнаружены гонки harness: DOM snapshot
попадал между CSS breakpoint и React mobile mount, либо сохранял уже скрытый
SW update control. Общий helper теперь ждёт согласованный shell и измеряет
только connected/visible controls в одном DOM snapshot; минимумы44/36/32px не
снижены. Вход ожидает первоначальный auth read до заполнения и networkidle
после профиля перед переходом. Проверки unexpected pageerror и ролей сохранены;
финальный полный прогон завершился без ошибок. В контрактном тесте исправлены
точные accessible selectors, включающие текст подсказок, без изменения UI.
