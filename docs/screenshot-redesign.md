## Карта макетов

Уточнение заказчика19.10.2026: раздел из макета «Клиенты» называется
«Семьи и родители», а человек в платежах — «Участник».
[Словарь сущностей](system-glossary.md) фиксирует значения терминов.

| Макет | Раздел и реальные данные |
| --- | --- |
| Главная | Обзор по роли, участники/группы/посещения, ближайшие занятия, финансовые показатели |
| Клиенты, семья | Семьи, контакты, дети, создание аккаунта родителя |
| Ребёнок | Основное, группы, посещения, платежи/абонементы, документы |
| Группы и расписание | Существующие группы, составы, четыре режима, занятия и календарь |
| Посещения | Действующие журналы, причины пропуска и история коррекций |
| Платежи | Тарифы, абонементы, журнал, ручная оплата и iPay/ЕРИП |
| Тренер | Сотрудники, назначенные группы и занятия, права управления |
| Уведомления | Личная серверная лента событий и прочитанное |
| Отчёты | Посещаемость и финансы из реальных записей |
| Настройки | Профиль, филиалы, интерфейс с desktop-only сворачиванием |
| PWA/вход | Настоящие роли, кабинет родителя, установка и адаптивная навигация |

## Ограничения проверки

Макеты задают структуру и визуальную систему; имена, суммы и фотографии на них
не являются данными клуба. Исходная эмблема PRIDE сохраняется. Родитель видит
только явно привязанную семью. Онлайн-платёж требует подтверждения провайдера;
переход по ссылке и возврат браузера сами по себе не подтверждают оплату.
Настройка реального merchant/секретов и приёмка физических устройств проверяются
отдельно; прежний PASS #188 не переносится на этот этап.
