### Восстановление WebKit

Первые два запуска остановились **до браузерных проверок**: не было `libGLESv2.so.2`
в системном ldconfig cache. Root/sudo недоступны. Официальный Debian13 пакет
`libgles2 1.7.0-1+b2` распакован в пользовательский каталог; версия, URL и SHA256 —
[webkit-dependency.json](webkit-dependency.json). `ldd`, `ctypes.CDLL`, настоящий
запуск WebKit26.5 и DOM smoke подтвердили загрузку библиотеки.

Для WebKit использован `LD_LIBRARY_PATH` с этим каталогом и
`PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1`: только предварительная проверка
Playwright через системный ldconfig не учитывает пользовательскую библиотеку.
Проверки самого браузера/приложения сохранены. В штатном CI используется
`playwright install --with-deps`, этого локального обхода диагностики там нет.
