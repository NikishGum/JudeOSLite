# Проверка прототипа

20.10.2026, Chrome через CUA. Штатный browser-client встроенного браузера отказал с `privileged native pipe bridge is not available; browser-client is not trusted`; UI проверен через доступный Chrome, без изменения настроек безопасности.

- Два варианта: настольная ширина 1280, мобильная 390; отдельно карточка Б при 320. Горизонтального переполнения DOM нет. На мобильном при открытии карточки скрывается повторная шапка раздела, возврат сохраняет фильтры.
- Снимки в evidence/ открыты и визуально просмотрены. Полные снимки Chrome исключают полосу прокрутки; это может убрать крайние 15 px правого внешнего поля, а не содержание экрана.
- Локальный Rubik загружен. Исходные CSS-токены импортированы, без новых брендовых значений. Семантические цвета взяты из существующего Working Panel.
- Проверены: создание мокового администратора с ролью/филиалом, ошибка несовпадения паролей и успешный повтор, назначение существующего аккаунта без дубля, поиск созданного сотрудника, смена пароля, отключение всего доступа с сохранением назначений, снятие одной роли с сохранением другой, сочетание role+branch по одному назначению, пустой результат.
- Подписи полей, текст статусов, нативный dialog с защищённым фокусом и Escape, видимый focus-visible, reduced motion. Кнопки и поля минимум 44 px; основной мобильный текст 16 px, вспомогательные подписи 12–14 px согласно рабочей системе.
- `node --check staff.js` — PASS.
- Impeccable detect запущен один раз. Парсеры htmlparser2/css-select/css-tree/domutils недоступны, использован ограниченный regex-режим, findings=[]; это не полноценная автоматическая проверка CSS/контраста. Текстовые цвета проверены отдельно численно.
- Без live API, базы и production-учётных записей. Моковая смена пароля не меняет реальные данные; тестовые значения не записаны в источники или объект аккаунта. Production-авторизация, ошибки сети, серверные конфликты и реальные сессии вне объёма прототипа.

Пользовательская корректировка: удалено разделение «Все сотрудники / Тренеры филиала», оставлен один реестр; роли и филиалы — фильтры и назначения.

Независимый Impeccable finish review: **ship** после одной пачки исправлений. Два P2 устранены: фокус после сохранения восстанавливается на новой DOM-карточке/строке; мобильный возврат из диалога А закрывает окно. В браузере подтверждено: после save в Б activeElement = H2#person-heading; после возврата А dialog.open=false, фокус на имени в списке. Открытие последней строки в мобильном Б прокручивает начало карточки к верху (detailTop=0). Reviewer повторно открыл пять снимков и проверил обе правки; заключение относится к этим замечаниям и объёму локального прототипа.

Контраст: основной текст на белом 15.43:1, secondary на #EFF3F9 4.88:1, белый на brand 5.16:1, success 6.17:1, warning 6.03:1. Мобильные размеры базовых кнопок не меньше 44 px; имени в строке также выделена полная высота нажатия.

Следующий шаг — оценка заказчиком двух композиций. Перенос в production не выполнялся.
