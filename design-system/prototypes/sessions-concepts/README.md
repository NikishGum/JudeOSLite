# Занятия — два UX-прототипа

Самостоятельный HTML/CSS/JS-раздел без навигационной оболочки, сторонних библиотек и API. Создан по запросу заказчика 20.10.2026. Данные, имена, отметки и фиксированное время 16:20 вымышлены; изменения живут до перезагрузки страницы.

## Просмотр

Из корня репозитория:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

- [Повестка дня](http://127.0.0.1:8766/design-system/prototypes/sessions-concepts/index.html?concept=day)
- [Обзор недели](http://127.0.0.1:8766/design-system/prototypes/sessions-concepts/index.html?concept=week)

Можно открыть `index.html` напрямую: используются только относительные локальные ресурсы. Переключатель сверху относится к сравнению прототипов, а не к будущей навигации приложения.

## Идеи

**Повестка дня — основной вариант.** Приоритет заказчика: быстро открыть журнал и управлять сегодняшними занятиями. Семь дней с количеством занятий заменяют отдельные поля начала/конца и кнопку обновления. Фильтры работают сразу. Текущий журнал выделен, завершённые сегодняшние занятия свёрнуты в раскрывающийся блок. Каждая строка связывает время, группу, фактического тренера, состояние журнала и действие. Перенос, замена и отмена доступны через кнопку действий конкретного занятия.

**Обзор недели — альтернатива для планирования.** Временная сетка показывает длительность, интервалы и распределение по дням. Заголовок дня открывает повестку, занятие — подробности и действия. На телефоне сетка заменяется выбором дня и читаемым списком; сжимать семь колонок до нечитаемого размера не нужно.

Оба варианта используют общий набор моковых занятий, фильтры и формы. Выбранная дата и фильтры сохраняются при переключении идеи.

## Что можно попробовать

- Выбрать день, перейти стрелками или через календарную дату, вернуться к сегодняшнему дню.
- Отфильтровать по группе, тренеру и статусу; получить пустое состояние и сбросить фильтры.
- Продолжить журнал 16:00 и изменить демонстрационные отметки четырёх участников.
- Открыть действия занятия 17:30, заменить тренера, перенести его на 18:00 или отменить с причиной.
- Добавить разовое занятие на 20:00 длительностью 60 минут. В демо доступны интервалы 13:00–21:00.
- Раскрыть завершённые занятия и открыть журнал для просмотра.

Формы показывают последствия изменения только одного занятия. Для отмены открытого журнала требуется подтверждение сохранения существующих отметок. У завершённого занятия перенос, замена и отмена недоступны. Демо проверяет пересечение группы/тренера при добавлении, переносе и замене. Эти дополнительные удобства и ограничения демо являются предложением, не утверждённым изменением требований production.

## Визуальная основа и границы

Источник оформления: корневой `DESIGN.md`, `design-system/README.md`, локальные `fonts/fonts.css`, `tokens.css` и существующий `frontend/src/app/app.css`. Rubik, основной акцент `#DB0C0C`, hover `#323232`, поверхности `#FFFFFF` / `#F5F7FA` / `#EFF3F9`, текст `#212529` / `#626B72`, кнопки 5px, поля 10px, панели 20px. Семантические оттенки `--panel-success` и `--panel-warning` переиспользованы из действующего приложения и не объявляются исходными цветами бренда.

Это исследование UX, не реализация live issue и не замена раздела React. Приложение, API, глобальная дизайн-система и данные клуба не изменены. Произвольный период, постоянные правила расписания и полноценный журнал остаются за рамками этих двух концепций.

Детали итогового оформления — в `DESIGN.md` рядом с этим файлом; результаты проверки — в `REVIEW.md`.
