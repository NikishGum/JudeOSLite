# Прототип рабочего пространства PRIDE

Самостоятельные HTML/CSS/JS для обсуждения редизайна после v1. Подготовлено 12.10.2026. Файлы React, API, миграции, зависимости и сборка приложения не изменены.

## Открыть

Из корня этого checkout:

```sh
python3 -m http.server 5178 --bind 127.0.0.1
```

Открыть [панель просмотра](http://127.0.0.1:5178/design-system/prototypes/dashboard/preview.html). Для прямого просмотра — [index.html](index.html). Папку можно открыть локально через preview.html; HTTP рекомендуется для одинакового поведения браузеров.

Панель просмотра переключает роль, ПК/телефон (390 × 844), загрузку, пустой экран и ошибку. «Ошибка сохранения» имитирует отсутствие связи в журнале. Смена роли/сценария перезапускает данные; смена размера экрана сохраняет текущую работу.

## Что можно попробовать

- Владелец: период и группа отчёта, филиал по строке сравнения, статистика, история изменений.
- Администратор: занятие и журнал, отмена/замена тренера, поиск/карточка/добавление вымышленного участника, поштучное исправление закрытой отметки с причиной.
- Тренер: открыть назначенное занятие, отметить присутствие/причину отсутствия, вернуться к отметке, подтвердить завершение с неотмеченными.
- Телефон: нижняя навигация, меню «Ещё», нижняя панель причины и подтверждения. На ПК панели открываются справа.

Все данные синтетические. Изменения хранятся в памяти вкладки до перезагрузки. Нет API, БД, авторизации или отправки форм. Переключатель роли — инструмент демонстрации, не предложение менять роль сотрудника в приложении. Не вводить реальные персональные данные.

## Границы демонстрации

Показана выборка участников; счётчики активного реестра представляют полный вымышленный филиал. Отчёт недели/месяца — синтетическая история; за сегодня вычисляется по деможурналам. Закрытие/коррекция деможурнала обновляет отчёт в той же вкладке. Переключение роли сбрасывает сценарий; общих серверных данных между ролями нет. Форма участника показывает сокращённый сценарий, а не полную реализацию v1.

Права в прототипе ограничивают видимую навигацию и выборку, но не обеспечивают безопасность. Журнал не восстанавливается после перезагрузки, изменения аудита не записываются. PWA и реальные мобильные устройства здесь не проверяются.
