# PRIDE · shadcn-шаблон

Самостоятельный локальный React/TypeScript/Vite-шаблон с официальным shadcn/ui (Radix, Nova, Tailwind 4). Подготовлен 16.10.2026 от актуального main `78c1b692a35c4844d5263d6e4e0fb1fa7c64448f` по прямому поручению заказчика.

```sh
cd design-system/prototypes/shadcn-app
npm ci
npm run dev
```

Открыть [127.0.0.1:5180](http://127.0.0.1:5180). `npm run build` проверяет TypeScript и собирает production; `npm run preview` показывает сборку на том же порту (сначала остановить dev). Проверено на Node 25.9.0/npm 11.12.1; это отдельный инструмент, требования Node основного frontend не менялись.

## Что можно проверить

- Левый Sidebar сворачивается до иконок; на телефоне открывается как Sheet. Кнопка, Escape, фокус и возврат доступны. На desktop работает штатное Cmd/Ctrl+B.
- Главная, занятия, участники, группы, журналы, статистика, сотрудники, филиалы, история; отдельно подборка registries.
- Контекст сети/филиала; демонстрационные роли owner/administrator/trainer и доступные им разделы. Роль тренера ограничивает список занятий синтетическим назначением Елены Пример. Это визуальная демонстрация, не авторизация.
- Поиск и фильтры участников/занятий, карточки в Sheet, переход из группы в занятия с поиском, back/forward по разделам.
- Состояния «Обычный экран», «Загрузка», «Нет данных», «Ошибка» и восстановление. Загрузка/ошибка управляются вручную для оценки интерфейса; это не сетевые запросы.
- Адаптивные таблицы на телефоне показывают подписи, значения и действия без горизонтального скролла.

Это шаблон интерфейса с синтетическими данными, без API/логина/изменения CRM, persistence или PWA. Предметные формы создания, четыре режима редактора расписания и полноценный журнал остаются в основном приложении; их серверные операции здесь не имитируются. Демодень фиксирован: 16.10.2026, Europe/Minsk. Данные сбрасываются при перезагрузке.
