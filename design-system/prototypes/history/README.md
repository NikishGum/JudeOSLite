## Панель таблицы

- Поиск, филиал, период и кнопка «Фильтры» находятся в основной строке с видимыми подписями. Высота контролов — 48 px. Нативный select сохраняет список и клавиатуру; `appearance: none` и явная высота исправляют сжатие на macOS/WebKit.
- Действие и сотрудник раскрываются на месте; произвольный период раскрывает даты. Фильтры применяются сразу. При закрытии панели активные условия остаются видны отдельными удаляемыми кнопками; счётчик на кнопке показывает дополнительные условия.
- Ниже — число результатов, фактический период, сброс и обновление. Обновление сохраняет выбор. Нет самостоятельной формы с кнопкой «Показать историю».
- На промежуточной ширине поиск занимает отдельную строку. До 540 px филиал/период имеют всю строку с подписью слева; длинные значения не приходится сжимать в половину экрана.

## Поиск по журналу

Свободный запрос дополняет точные фильтры. Поиск применяет **И** ко всем словам в любом порядке: `Калиновская исправлена` находит одну запись. Это поиск по подстроке, без морфологии, нечёткого совпадения или специального синтаксиса. Регистр и различие «е/ё» игнорируются. Ищет по автору, филиалу, названию/коду действия, типу и ID записи/события. Начальный `#` у ID можно вставить вместе с номером.

Задержка 300 ms предотвращает перерисовку на каждом символе; Enter применяет запрос сразу. Совпадения в видимых данных подсвечиваются. Escape или крестик очищают только запрос, сохраняя фильтры. После пустого результата предложено очистить запрос или расширить ограничения. «Сбросить всё» возвращает исходные семь дней и снимает условия.

**Предложение для реального приложения:** выполнять такой поиск на сервере по всему доступному пользователю аудиту, с теми же фильтрами/правами, сбросом курсора при изменении запроса и отменой устаревших запросов. Нельзя молча искать только в загруженных 50 событиях. Нужны отдельные договорённости об endpoint, правилах поиска и счётчике: текущий API не предоставляет свободный поиск, фильтр сотрудника и общий total. Это прототип UX, серверный поиск здесь не реализован.

## Данные и границы

Все 28 событий, имена и ID синтетические; дата примера — 20 октября 2026,
Europe/Minsk. Семь дней включают 26 событий. Использован публичный envelope:
время, автор, филиал, действие, тип/ID записи. Private payload, контакты и причины
коррекций не показаны. Имена/названия отражают текущие значения, не исторический снимок.

Никакие React-компоненты, API, права или глобальные токены не изменены.
