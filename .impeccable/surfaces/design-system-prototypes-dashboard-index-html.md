# PRIDE · Дашборд

Режим: Operate. Самостоятельный HTML/CSS/JS-прототип для будущего редизайна после v1, независимо от React.

Подтверждено 12.10.2026: три роли с переключением в демонстрации, владельцу обзор сети, администратору и тренеру занятия; code-first. Выбрана «Рабочая панель»: навигация слева, рабочая область в центре, день справа. Seed f62fcfae, структура 3; варианты 3/5/4 в .impeccable/dashboard-options.json.

На телефоне основной сценарий предшествует второстепенным данным; у администратора занятие выше счётчиков. Владелец сравнивает филиалы; тренер проходит карточки кнопками и явно завершает журнал с предупреждением о неотмеченных. Филиал и назначение ограничивают контекст.

Проверяемый момент: группа → отфильтрованное расписание → журнал → причина отсутствия → завершение. Синтетические данные отмечены; API и сохранения между сессиями нет.

Открытые решения: плотность ПК, состав первого экрана владельца, предложенная семантическая палитра, удобство нижней навигации. Требования implementation issue согласовать после оценки прототипа. Визуальная основа наследуется из корневого DESIGN.md, детали реализации — prototype-local DESIGN.md.
