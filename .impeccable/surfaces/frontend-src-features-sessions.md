# Занятия · #216

20.10.2026 · Operate · продолжение существующего интерфейса PRIDE.

- Задача сотрудников — увидеть неделю, открыть конкретную тренировку и работать в существующем журнале. Визуальная основа: PRODUCT.md, DESIGN.md, design-system/README.md; Rubik, красный акцент, белые панели. Новая визуальная система не вводится.
- Недельные колонки списков без почасовой сетки при ширине содержимого ≥840px, включая обычный ноутбук 1280px с открытой Sidebar; ниже — вертикальные дни. Семь дней, включая пустые; одинаковые фильтры карточек и счётчиков. Спортсменов в календаре нет. Дни имеют серую поверхность, занятия — белую с границей; сегодняшний день обозначен. На телефоне фильтры раскрываются отдельно.
- Вся карточка, включая время и статус, ведёт на постоянную страницу session; меню управления отдельно. Контекст календаря передаётся разрешёнными ID/датами/видом/фильтрами/scroll. На странице состав с поиском слева, рабочая область справа. Клик по спортсмену переключает сведения без записи, возврат в прежний журнал сохраняет последовательную отметку. На mobile состав и рабочая область идут вертикально, выбор переводит фокус к сведениям.
- Уточнение заказчика20.10: правая область в будущем объединит достижения, пояс, упражнения/подтягивания и опциональные домашние задания выбранного спортсмена. Сейчас показываются только существующие данные; новые сущности/моковые достижения не добавляются.
- Сверху страницы «К текущей тренировке»: свой actual trainer, реальный интервал, не closed/cancelled. Чтение разрешённых назначений, без auto-open; на уже просматриваемую текущую тренировку ссылка не дублируется.
- Реальные GET читают датированные членства до freeze и attendance_records после freeze. Без миграций, новой записи журнала или подмены неизвестной сводки нулями. Роли/история/версии сохраняются.
- Проверяемые состояния: planned/future/empty/frozen/cancelled, transfers/archive/replacement, ошибки/повтор/409, длинные имена/45 участников, прямой URL/legacy/back/reload, 320/390/768/1280/1440px, клавиатура/фокус/44px. Синтетические данные допускаются только в тестах.
