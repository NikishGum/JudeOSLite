# Занятия: две UX-концепции

Mode: Operate. Scope: самостоятельные прототипы раздела без оболочки приложения.

Заказчик 20.10.2026 попросил два локальных HTML/CSS/JS-варианта с моковыми данными и точным наследованием текущей дизайн-системы. В ответе в этом чате подтвердил приоритет: быстро открыть журнал и управлять занятиями сегодня.

Основная концепция — повестка дня: текущий журнал и предстоящие занятия первыми, завершённые сегодня в раскрывающемся блоке, фильтры применяются сразу, действия привязаны к занятию. Альтернатива — недельная временная сетка; на телефоне она становится списком выбранного дня. Демо переключатель вариантов не является частью продуктовой навигации.

Общие формы: разовое занятие, замена фактического тренера, перенос и отмена с причиной; журнал представлен только демонстрацией перехода с четырьмя синтетическими участниками. Изменения до перезагрузки, никакого API или production интеграции. Календарь фиксирован на 19–25.10.2026, текущее время демо 20.10 16:20.

Не решено: какая концепция будет выбрана; перенос в React; произвольный период и постоянные правила расписания. Эти идеи не утверждают новые product требования и не заменяют live issues.
